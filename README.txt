Project Overview

This project analyzes three separate datasets as part of the ECON 424 final assignment. Each question focuses on a different econometric or data-driven problem:

Q1: Predicting employee ratings using text analysis and machine learning.

Q2: Investigating potential hiring discrimination through name-based patterns and text sentiment.

Q3: Analyzing macroeconomic conditions using simulated stock market data and annual report text.

The project combines quantitative modelling, natural language processing (NLP), data visualization, and economic interpretation.
